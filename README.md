## The Problem
- Crypto scams stole **billions** last year.
- Victims often have **no recourse** — especially in developing countries.
- Existing tools are fragmented, paid, or centralized.

## Why AEGIS?
- **Prevention first**: Real-time wallet screening.
- **Transparency**: Public, tamper-proof scam profiles on IPFS + blockchain.
- **Decentralized**: No single point of failure or control.
- **Incentivized**: Future token rewards for reporters and verifiers.
- **Free forever** for individuals.

## Core Features
- **Scanner** — Risk scoring from public data + community reports.
- **Reporter** — AI-assisted evidence packaging.
- **Public Dashboard** — Search known scammers.
- **Alerts & Integrations** (Roadmap) — Exchange notifications, wallet monitoring.

## Architecture Overview
- Open source
- Multi-chain support (Ethereum, BSC, Solana, etc.)
- AI + On-chain indexing
- IPFS for evidence storage

## Roadmap
